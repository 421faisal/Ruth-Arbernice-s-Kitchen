# Photo library

Full-size originals of the stock photos, renamed by what they show. The website uses optimized
WebP copies in `public/images/` (same names). `SOURCES.json` maps each name to its original Pexels file.

Pexels photos are free to use commercially without attribution (https://www.pexels.com/license/).
They are stand-ins: replace dish photos with real photos of the kitchen's own food from the owner
dashboard (Menu & prices → click a dish → Upload a photo) as soon as possible.
